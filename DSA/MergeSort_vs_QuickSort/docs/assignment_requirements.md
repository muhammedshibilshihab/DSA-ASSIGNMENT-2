# Assignment Requirements

**Topic:** Comparison of Merge Sort and Quick Sort for Fixed-Length Social Media IDs

**Given Input:** 324, 125, 456, 218, 102, 389, 275, 147

## Requirements

1. Implement the required programs in C.
2. Execute the programs using the given input data.
3. Record important intermediate steps using suitable trace tables.
4. Compare the performance of the specified algorithms.
5. Determine time complexity and, wherever applicable, space complexity.
6. Justify the suitable approach based on execution and complexity analysis.
7. Prepare a GitHub repository containing:
   - Source code
   - Input data
   - Output
   - Trace tables
   - Complexity analysis
   - Comparison table
   - Final conclusion

## Where Each Requirement Is Fulfilled in This Repository

| Input data | `input/input.txt` |

| Trace tables | `trace/merge_sort_trace.txt`, `trace/quick_sort_trace.txt` |
| Complexity analysis | `analysis/complexity_analysis.md` |
| Comparison table | `analysis/comparison.md` |
| Final conclusion | `analysis/conclusion.md` |
